# Office Automator

Automate the process of adding shortcuts


### DEVELOPED BY WESLLEY

I developed this script to simplify the process of creating shortcuts for Word, Excel, and PowerPoint Online as applications within Google Chrome; the template can be adapted to suit your specific needs.

It copies the corresponding icons to a designated Chrome folder and creates desktop shortcuts using the correct icons.

I have not violated any rules, as I have merely automated the creation of shortcuts for Microsoft Office web applications—a task that can already be performed manually (and for free), albeit more time-consumingly.

Installs Word, Excel, and PowerPoint Online as apps in Chrome

Copies the icons to the Chrome folder and applies them

> [!IMPORTANT]
> Urgent info that needs immediate user attention to avoid problems.
> For this script to work, you must first open PowerShell and run the following command.

> [!NOTE]
> It’s temporary and only works in that terminal instance.

Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass

> [!WARNING]
> Modifies Windows policy to allow the execution of scripts PERMANENTLY

Set-ExecutionPolicy -Scope CurrentUser -ExecutionPolicy RemoteSigned

> [!TIP]
> Revert permission
> Set-ExecutionPolicy -Scope CurrentUser -ExecutionPolicy Restricted
